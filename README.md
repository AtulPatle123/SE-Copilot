# SE-Copilot

A React + TypeScript AI-style chatbot interface with a dummy API layer, modern custom CSS, and a scalable folder structure.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`

## Architecture

- `src/domain`: shared domain models
- `src/features/chat`: chat feature logic, reducer, service, and UI components
- `src/shared`: reusable utilities
- `src/styles`: global styling

## Notes

The current response flow uses a dummy async service so you can later replace it with a real backend or AI API without rewriting the UI layer.
